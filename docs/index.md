# rseng-agent-skills

Research software engineering (RSEng) skills for AI coding agents:
Claude Code, GitHub Copilot, Cursor, Codex CLI and Gemini CLI. The pack
holds 67 skills covering research software engineering practice, plus
(for Claude Code) 14 slash commands and 6 subagents.

Start with the [quickstart](user/quickstart.md), or read about the
[architecture](dev/architecture.md) if you want to contribute.

Part of the skill content was originally adapted from
community-maintained CC-BY-4.0 material and is not endorsed by those
projects; the repository's ATTRIBUTION.md holds the full credit record.
