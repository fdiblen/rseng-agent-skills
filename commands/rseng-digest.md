Draft the high-level project digest, following the two-altitude log
practice in ${CLAUDE_PLUGIN_ROOT}/skills/rseng-project-tracking/SKILL.md.

Steps:

1. Establish the period: since the last digest entry, last milestone
   or $ARGUMENTS (e.g. "last month").
2. Gather the raw story: the detailed journal if one exists, merged
   PRs and closed issues, milestone changes, release tags, decision
   log entries, lessons recorded.
3. Distill a few paragraphs: what moved, what changed direction,
   current state and what is next - written for the PI report and
   the returning collaborator, not for developers.
4. Note it is an AI-drafted record pending human review, and offer
   to append it to the project's log location once approved.
